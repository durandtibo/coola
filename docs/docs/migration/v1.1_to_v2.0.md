# Migration Guide: v1.1 to v2.0

This guide explains how to migrate your code from `coola` version `1.1.x` to version `2.0.x`.

## Overview of Changes

The main changes in version 2.0 are the `expand` protocol of `coola.recursive` (the engine now
recurses, and a transformer only describes the children of one object) and the single child finder
of `coola.iterator` (one registry and one `find_children` for `dfs_iterate` and `bfs_iterate`).
`coola.factory` has one way to import a target, one way to call it and one way to ask what it builds.
`coola.random` has one seed domain, a strict `set_rng_state` and one registry type that subclasses
`coola.registry.Registry`. `coola.summary` has one engine, one extension point (a summarizer returns a
string or a `Node`) and one option object (`SummaryConfig`): the options are the keyword arguments of
`summarize`. `coola.registry` has one storage class (`Registry`) and one dispatch class
(`TypeRegistry`): the registries of the packages are `TypeRegistry` subclasses, a type that cannot be a
key (every dataclass) is registered as a fallback predicate, and the registries can be pickled.

`coola.utils` is now a leaf of the package layering: the functions that turn values into text are in
`coola.formatting`, the default
registries and the plugin loader are in `coola.registry`, and `coola.utils.imports` has one definition
of "available" (section 19).

## Migration Checklist

- [ ] Port the custom `coola.recursive` transformers to `expand` (section 1)
- [ ] Port the custom `coola.iterator` iterators and child finders to `find_children` (section 2)
- [ ] Replace `_init_: __new__` and the `_init_` names that start with `_` by a public class method,
      and resolve the nested configurations before passing them under an allow-list (section 3)
- [ ] Replace the removed names of `coola.random`, and give `set_rng_state` a state with the registered
      keys (section 4)
- [ ] Port the custom `coola.summary` summarizers to `summarize(data, config, *, compact)`, move the
      options of the summarizers to the arguments of `summarize`, and read the new layout (section 5)
- [ ] Replace `DataclassMarker`, `find`, `resolve_or`, `BaseTypeDispatchRegistry`, the `equal_nan`
      argument of `equal` and the positional `exist_ok` (section 6)

- [ ] Port the custom `coola.hashing` hashers to `encode`, replace `SupportsHash.hash` by
      `__coola_hash__`, move the secret policy to the registry, and replace the removed names
      (section 7). **Every hash and every stable identifier changes.**
- [ ] Rename `load` to `_load` in the custom `coola.io` loaders, drop their `equal`, remove `lock=`,
      import `add_uuid_suffix` from `coola.utils.path`, and call `str()` before `save_text`
      (section 8)
- [ ] Replace `generate_uuid4`, `generate_nano_id`, `generate_prefixed_id` and
      `generate_obfuscated_id`, rename `extract_object_id_timestamp`, pass the canonical form to the `extract_*` functions,
      pass `timestamp_ms` by keyword, replace `ObjectIdGenerator`, create a
      `SnowflakeIdGenerator(worker_id=...)` instead of calling `generate_snowflake_id`, and pass the
      options of the checksummed identifiers by keyword (section 9)
- [ ] Import the test marks from `coola.testing.marks`, import the fixture from
      `coola.testing.fixtures` (or load it with `pytest_plugins`), and remove `plural=` from
      `requires` (section 10)
- [ ] Pass the options of `to_flat_dict`, `flatten_mapping`, `merge_mappings` and
      `add_prefix_suffix_to_keys` by keyword, import `get_first_value` from `coola.utils.mapping`,
      and stop importing `try_sorted_list`, `SetToListTransformer` and the helpers of
      `coola.nested.polars` (section 11)
- [ ] Replace the removed names of `coola.validation` (`validate_str`, `validate_positive`,
      `validate_closed_range`, ...) with `validate_isinstance`, `validate_gt/ge/lt/le` and
      `validate_range`, and read the new messages (section 18)
- [ ] Update the import paths of `coola.utils` (section 19), replace the decorators and the
      `raise_<pkg>_missing_error` functions of `coola.utils.imports`, and pass the options of the
      formatting functions and `limit` of `smallest_items` by keyword
- [ ] Pass `force` of `configure_colorlog_logging` by keyword, read the new output of
      `str_pydantic_model` and `repr_pydantic_model` for nested models, and give `print_markdown` a
      `max_length` of at least 1 (section 20)

## Detailed Changes

### 1. Recursive Transformers: the `expand` Protocol

| Before                                                                                  | After                                                                                       |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `Transformer.transform(data, func, registry)`                                           | `Transformer.expand(data)`: returns `None` (a leaf) or `(children, rebuild)`                |
| A transformer recurses through `registry.transform`                                     | The engine recurses: a transformer cannot forget the cycle check or the depth limit         |
| A dataclass is a leaf; `enter_dataclasses()` enters it                                  | A dataclass is entered by default; `enter_dataclasses` is removed                           |
| `dfs_iterate` and `bfs_iterate`: a dataclass is a leaf; `enter_dataclasses()` enters it | A dataclass is entered by default; `enter_dataclasses` is removed from `coola.iterator`     |
| `dataclasses.replace` rebuilds a dataclass                                              | A shallow copy with the fields set: `init=False` fields are transformed, no `__post_init__` |
| `ConditionalTransformer`                                                                | Removed: guard `func`, or register `IdentityTransformer` for the type                       |
| `recursive_apply(data, func, registry)`                                                 | `recursive_apply(data, func, registry=registry)`                                            |
| `KeyFilterTransformer()` with `func` as the key predicate                               | Removed (see section 11): use `coola.nested.remove_keys_if`                                 |
| `register_transformers(mapping, True)`                                                  | `register_transformers(mapping, exist_ok=True)`                                             |
| `RecursionError` for a deep structure                                                   | No limit: the traversal uses an explicit stack                                              |

**Before:**

```python
class PointTransformer(BaseTransformer[Point]):
    def transform(self, data, func, registry):
        return Point(registry.transform(data.x, func), registry.transform(data.y, func))
```

**After:**

```python
class PointTransformer(BaseTransformer[Point]):
    def expand(self, data):
        return [data.x, data.y], lambda xs: Point(*xs)
```

A plugin of the group `coola.recursive.transformers` that implements `transform` must be ported to
`expand`. To keep a dataclass as a leaf, register `DefaultTransformer()` for its type (`DefaultChildFinder()` for
`dfs_iterate` and `bfs_iterate`).

### 2. Iterators: One Child Finder for Both Orders

| Before                                                                                 | After                                                                                         |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `coola.iterator.dfs` and `coola.iterator.bfs`                                          | Removed: import from `coola.iterator`                                                         |
| `BaseIterator.iterate(data, registry)` (DFS) and `BaseChildFinder.find_children` (BFS) | `BaseChildFinder.find_children(data)`: returns the children, or `None` for a leaf             |
| `IteratorRegistry`, `PathRegistry`                                                     | Removed: `ChildFinderRegistry` serves both orders                                             |
| `register_iterators` and `register_child_finders`                                      | `register_child_finders(mapping, *, exist_ok=False)`                                          |
| `get_default_iterator_registry()`                                                      | `get_default_registry()` (alias `get_default_child_finder_registry()`)                        |
| `DefaultIterator`, `IterableIterator`, `MappingIterator`, `DataclassIterator`          | `DefaultChildFinder`, `IterableChildFinder`, `MappingChildFinder`, `DataclassChildFinder`     |
| A leaf overrides `is_leaf` (BFS)                                                       | A leaf returns `None` from `find_children`; an empty container returns an empty iterable      |
| `registry.iterate(data)` and `registry.find_children(data)`                            | Removed: use `dfs_iterate(data, registry=registry)` or `bfs_iterate(data, registry=registry)` |
| `dfs_iterate(data, registry)` and `bfs_iterate(data, registry)` (deprecated)           | `registry` is keyword-only                                                                    |
| Plugin groups `coola.iterator.dfs` and `coola.iterator.bfs`                            | One group: `coola.iterator.child_finders`                                                     |
| `RecursionError` for a `dfs_iterate` structure nested about a thousand levels          | No limit: both orders use an explicit stack or queue                                          |
| `range`, a user `Collection` and a user `collections.abc.Set` are entered              | They are leaves, like in `recursive_apply` (register a child finder to enter them)            |
| `bfs_iterate` could raise a false `Cycle detected` for objects built by a child finder | Fixed: the ancestors are compared by identity                                                 |

**Before:**

```python
class ReversedListIterator(BaseIterator[list]):
    def iterate(self, data, registry):
        for item in reversed(data):
            yield from registry.iterate(item)
```

**After:**

```python
class ReversedListChildFinder(BaseChildFinder[list]):
    def find_children(self, data):
        return reversed(data)
```

A child finder returns the children in the order they are visited, and the same order is used by
`dfs_iterate` and `bfs_iterate`: a custom order for one traversal only is no longer possible. A
plugin of the group `coola.iterator.dfs` or `coola.iterator.bfs` must register a `ChildFinder` in
`coola.iterator.child_finders` instead.

### 3. Factory: Strict Contracts

| Before                                                                                        | After                                                           |
| --------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| A target cannot receive an argument named `obj` or `cls`                                      | It receives every key that is not reserved, whatever its name   |
| `_init_="__new__"` or a name that starts with `_`                                             | `TypeError`: use a public class method or static method         |
| `_allowed_prefixes_` in the configuration of `resolve_object` (used when the caller has none) | Ignored: the allow-list always comes from the caller            |
| `factory(..., _allowed_prefixes_=[...])` with an argument that is `{"_target_": ...}`         | `ValueError`: resolve the nested configuration first            |
| `resolve_object` with a nested configuration and `allowed_prefixes`                           | `ValueError` (same reason)                                      |
| A `dict` with `_target_` and a `dict` subclass `cls`                                          | Built (the key `_target_` is reserved)                          |
| A `dict` without `_target_`                                                                   | Returned if it is an instance of `cls`, else `TypeError`        |
| `Counter({"_target_": 2})` passed to `resolve_object`                                         | Resolved as a configuration                                     |
| Missing module or attribute of a target                                                       | `ImportError: The target object does not exist: ...` everywhere |
| A target that returns `A \| B` with no subclass of `cls`                                      | Refused before the call                                         |
| `is_object_config({"_target_": 5}, int)`                                                      | `False` (was `TypeError`)                                       |
| Explicit `_init_="__init__"` with `resolve_object`                                            | The target is checked, like the default                         |

**Before:**

```python
resolve_object({"_target_": "mypkg.Model", "_init_": "__new__"})
```

**After:**

```python
resolve_object({"_target_": "mypkg.Model", "_init_": "from_config", "config": {...}})
```

An allow-list is a filter on a path, not a sandbox: never allow a prefix that contains a function
that resolves its arguments (`"coola"`, `"coola.factory"`, `pickle`, `eval`, ...).

### 4. Random: One Seed Domain, One Registry

| Before                                                                              | After                                                                                   |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `RandomRandomManager` (`coola.random.random`)                                       | `PythonRandomManager` (`coola.random.python`)                                           |
| `numpy_seed(seed)` and `torch_seed(seed)`                                           | `NumpyRandomManager().seed(seed)` and `TorchRandomManager().seed(seed)`                 |
| `random_seed(seed, manager)`                                                        | `random_seed(seed, *, registry=None)`                                                   |
| `register_managers(mapping, True)`                                                  | `register_managers(mapping, exist_ok=True)`                                             |
| `manager.manual_seed(-1)`, `1.5`, `True`, `2**63` accepted or folded                | `TypeError` / `ValueError`: every entry validates the seed                              |
| NumPy: `manual_seed(2**32 + 1)` gives the numbers of `manual_seed(1)`               | A seed `>= 2**32` is split in two 32-bit words: its numbers change                      |
| `registry.has_manager(key)` and `registry.find_manager(key)`                        | `key in registry` (or `registry.has(key)`) and `registry[key]`                          |
| `set_rng_state` with different keys logs a warning and restores a part of the state | `ValueError`, nothing restored; all the managers are restored before an error is raised |
| `get_random_seed(seed)` in `[-2**63, 2**63 - 1)`                                    | In `[0, 2**63 - 1)`, valid for `manual_seed`: the value for a given seed changes        |
| `get_torch_generator(random_seed=1, device)` (not exported)                         | `get_torch_generator(seed, *, device="cpu")` from `coola.random`; `seed` is required    |
| `repr(RandomManagerRegistry)` has a `(state): Registry(...)` line                   | The managers are listed directly                                                        |

A state saved with torch and restored on a machine without torch now raises a `ValueError`. Restore
it into a registry with the same keys.

### 5. Summary: One Engine, One Option Object

| Before                                                                                          | After                                                                                                    |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `Summarizer.summarize(data, registry, depth, max_depth)` returns a `str` and recurses           | `Summarizer.summarize(data, config, *, compact)` returns a `str` (a leaf) or a `Node` (a container)      |
| `registry.summarize(data, depth, max_depth)`                                                    | `registry.summarize(data, config=None)` with a `SummaryConfig`                                           |
| `SequenceSummarizer(max_items=3)`, `DefaultSummarizer(max_characters=50)`, `num_spaces=4`       | `summarize(data, max_items=3, max_characters=50)`; the indentation is 2 spaces and is not an option      |
| `NDArraySummarizer(show_data=True)`, `PandasDataFrameSummarizer(max_fields=2)`                  | `summarize(data, show_data=True)`, `summarize(data, max_items=2)`                                        |
| `max_items=-1` and `max_characters=-1` for "no limit"                                           | `max_items=None` and `max_characters=None`                                                               |
| `summarize(data, 2)` and `register_summarizers(mapping, True)`                                  | `TypeError`: `summarize(data, max_depth=2)` and `register_summarizers(mapping, exist_ok=True)`           |
| `max_depth=True` and `max_depth=1.5` accepted                                                   | `TypeError`                                                                                              |
| `BaseCollectionSummarizer`, `BaseFieldsSummarizer`, `MAX_FIELDS`                                | Removed. `format_fields(fields, max_fields)` has no default for `max_fields`                             |
| `BaseMetadataSummarizer(show_data)` with `_describe(data)`                                      | `BaseMetadataSummarizer()` with `_describe(data)` returning fields; a table returns `("columns", pairs)` |
| `repr` and `equal` to write in every summarizer                                                 | `BaseSummarizer` gives `Name()` and "same type"                                                          |
| `RecursionError` for a nesting of a few hundred levels                                          | No `RecursionError`: the engine uses an explicit stack                                                   |
| A self-referencing container is repeated up to `max_depth`                                      | `<cycle>` where it comes back                                                                            |
| A `__len__`, a property or a `__iter__` that raises makes `summarize` raise                     | `<class ...> <summary failed: ExcType>` and the rest of the summary is intact                            |
| `field(repr=False)` fields of a dataclass are printed                                           | They are not shown                                                                                       |
| `UserString` is a list of characters, `MappingProxyType` is printed whole                       | A leaf, and a mapping                                                                                    |
| A named tuple has the labels `(0)`, `(1)`                                                       | The field names                                                                                          |
| A container at the display depth is `[0, 1, 2, 3, 4] ...`, its `str` is computed in full        | `[0, 1, 2, 3, 4, ...]`, bounded work (three levels, `max_items` items)                                   |
| Hidden entries: `...`; empty container: `<class 'list'> []`; nested levels indented by 2 then 4 | `... (+N more)`; `<class 'list'> (length=0)`; 2 spaces per level                                         |
| A frame, a table or a dataset lists 10 columns                                                  | It lists `max_items` (5) columns                                                                         |

A custom summarizer that returned a string only needs the new signature:

```python
from coola.summary import BaseSummarizer, Node, SummaryConfig


class PointSummarizer(BaseSummarizer[Point]):
    def summarize(self, data: Point, config: SummaryConfig, *, compact: bool) -> str:
        return f"Point(x={data.x}, y={data.y})"  # a leaf


class TreeSummarizer(BaseSummarizer[Tree]):
    def summarize(self, data: Tree, config: SummaryConfig, *, compact: bool) -> Node:
        # a container: the engine recurses, summarizes the children with the summarizer of their
        # type and applies max_items, max_depth and the cycle check
        return Node(
            f"Tree (children={len(data.children)})", enumerate(data.children), len(data.children)
        )
```

A summarizer must be pure and cheap: it does not call the registry, does not recurse and returns
the children lazily. A plugin of the entry-point group `coola.summary.summarizers` that implemented
`summarize(data, registry, depth, max_depth)` must be ported. The options that were per type
(`max_items=3` for lists and 10 for dicts) do not exist any more: register a summarizer that
returns a `Node` with a smaller `total` if you need it. The text of a summary is meant to be read,
not parsed, and its layout changes in this release.

### 6. Registry: Two Classes, Fallbacks, Pickling

| Before                                                                                 | After                                                                                                  |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `registry.register(DataclassMarker, handler)`                                          | `registry.register_fallback(dataclasses.is_dataclass, handler)`                                        |
| `from coola.registry import DataclassMarker`                                           | Removed; the dataclass handler is in `registry.fallbacks()`, not in `items()` / `len()`                |
| `BaseTypeDispatchRegistry`, `registry.find(t)`, `registry.resolve_or(t)`               | Removed; the registries of the packages are `TypeRegistry` subclasses: use `registry.resolve(t)`       |
| `registry.register(key, value, True)`, `register_many(mapping, True)`                  | `exist_ok` is keyword-only: `register(key, value, exist_ok=True)`                                      |
| `registry.equal(other, equal_nan=True)`                                                | `registry.equal(other)`: the entries are compared with `==`, and a registry equals its copy            |
| `except RuntimeError` around `AlreadyRegisteredError`                                  | `AlreadyRegisteredError` is a `ValueError` only                                                        |
| A hasher for `object` makes the hashing fallbacks unreachable                          | `object` is the last resort everywhere: type > fallback > `object`                                     |
| `HasherRegistry.register_fallback(predicate, hasher)` accepts a duplicate predicate    | A duplicate predicate raises `AlreadyRegisteredError` (`exist_ok=True` replaces it, keeping its place) |
| `HasherRegistry.unregister_fallback(predicate)` returns `None`                         | It returns the hasher and raises `KeyNotRegisteredError` for an unknown predicate                      |
| `repr(registry)` printed `(state): TypeRegistry(...)`; a hashing `fallbacks` list      | One display: one `(key): value` line per entry, then `(fallback)` lines and the pending lazy groups    |
| `register_lazy(["builtins", "decimal"], f)` then `register_lazy("builtins", g)` failed | Both groups stay and load; `register_lazy` is a method of `TypeRegistry` only                          |
| `pickle.dumps(registry)` and `copy.deepcopy(registry)` raised `TypeError`              | They work; a `spawn` worker can receive a registry                                                     |

**Before:**

```python
from coola.registry import DataclassMarker

registry.register(DataclassMarker, MyDataclassHandler())
```

**After:**

```python
from dataclasses import is_dataclass

registry.register_fallback(is_dataclass, MyDataclassHandler())
```

A handler registered for the type of a dataclass still has priority over the fallback. A fallback
also supports the virtual subclasses of an abstract base class (the MRO lookup does not call
`issubclass`):
`registry.register_fallback(lambda t: issubclass(t, Sequence), handler)`.

### 7. Hashing: One Engine, `encode`, a New Format

**Every hash value changes** (new encoding, format version `coola-hash-2`, short leaves inlined in the preimage of their parent), so every stable
identifier changes too: `generate_stable_content_id` and `generate_stable_uuid5` return other values.
Regenerate any stored hash or identifier.

| Before                                                                                | After                                                                                                       |
| ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Hasher.hash(data, registry, *, length, ignore_unhashable)`                           | `Hasher.encode(data)`: returns `tagged(tag, payload)` (a leaf) or `Node(tag, children)`                     |
| A hasher calls `registry.hash(child, length=..., ignore_unhashable=...)`              | The children are in the `Node`; the engine hashes them                                                      |
| `hash_string`, `hash_bytes`, `hash_tagged`, `hash_enum`, `hash_path`                  | Removed: use `hash_object`; `tagged` and `digest` are the building blocks of a hasher                       |
| `SupportsHash.hash(registry, length, ignore_unhashable)`, `HashableHasher`            | `__coola_hash__(self) -> object` (the content, not a hash), `SupportsCoolaHash`, `ContentHasher`            |
| `PydanticModelHasher(on_secret=...)`, `hash_pydantic_model`, `unwrap_secrets`         | `SecretHasher(on_secret)` and `get_secret_hashers(on_secret)`, registered in a registry                     |
| `"exclude"` removed the key or the item of a secret                                   | `"exclude"` hashes a constant: the position of a secret is kept                                             |
| A secret in a dict or a dataclass raised, or was `TypeNotRegisteredError`             | The policy of the registry applies wherever the secret is                                                   |
| `hash_object(data, registry, 32)`, `register_hashers(mapping, True)`                  | Keyword-only: `hash_object(data, registry=registry, length=32)`, `register_hashers(mapping, exist_ok=True)` |
| `HasherRegistry.hash(data, 16)`                                                       | `HasherRegistry.hash(data, length=16)`                                                                      |
| `ValueError("... nested too deeply")` at about 500 levels                             | No limit: the traversal uses an explicit stack                                                              |
| A DAG costs one visit per path                                                        | A shared container is hashed once                                                                           |
| `length` applied to every node: `hash(x, length=16)` was not a prefix of `length=128` | One digest cut at the end: a hash is the start of the longer ones                                           |
| A dataclass field with `compare=False` was hashed                                     | Only the `compare=True` fields are hashed                                                                   |
| `memoryview` hashed like `bytes`; `UserString` and `MappingProxyType` failed          | Own tag (`memoryview`), `UserString` and `MappingProxyType` are hashed                                      |
| A pandas object named `NaN` and one named `None` had different hashes                 | Same hash                                                                                                   |

**Before:**

```python
class PointHasher(BaseHasher[Point]):
    def hash(self, data, registry, *, length=64, ignore_unhashable=False):
        return registry.hash((data.x, data.y), length=length, ignore_unhashable=ignore_unhashable)
```

**After:**

```python
class PointHasher(BaseHasher[Point]):
    def encode(self, data):
        return Node("Point", [data.x, data.y])
```

To reveal or exclude secrets, build a registry:

```python
registry = get_default_registry().copy()
registry.register_many(get_secret_hashers("reveal"), exist_ok=True)
hash_object(model, registry=registry)
```

### 8. I/O: Template Methods, No Lock

| Before                                                                     | After                                                                                       |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `BaseLoader.load(path)` is abstract and each loader calls `sanitize_path`  | `BaseLoader._load(path: Path)` is abstract; `load` is concrete and converts the path        |
| Every loader and saver implements `equal(other, equal_nan)`                | `equal` is concrete in `BaseLoader` and `BaseSaver`: same type and same `_display_fields()` |
| `InlineDisplayMixin` is a base of each format                              | It is a base of `BaseLoader` and `BaseSaver`                                                |
| `JsonLoader[T]`, `PickleSaver[T]`, `TorchLoader[T]`                        | `BaseLoader[Any]` / `BaseFileSaver[Any]`: the classes are not subscripted                   |
| `save_text(123, path)` writes `123`; `save_text(None, path)` writes `None` | `TypeError` for anything but a `str`: call `str()` first                                    |
| `TorchLoader(**kwargs)`, `weights_only` read from `kwargs`                 | `TorchLoader(*, weights_only=True, **kwargs)`; shown in the repr, compared by `equal()`     |
| `from coola.io import add_uuid_suffix`; `coola.io.utils`                   | `from coola.utils.path import add_uuid_suffix`                                              |
| `save_*(..., lock=True)`, `BaseFileSaver.save(..., lock=True)`             | `lock` is removed (`TypeError`); no `.lock` file, no heartbeat thread                       |
| Saves of one path are serialized                                           | Saves are atomic and never mix; which one wins is unspecified                               |
| `exist_ok=False` without hard links is protected by the lock               | Two processes creating the same file at the same instant can both succeed (last wins)       |
| `_fsync_file` opens the file read-only                                     | It opens it with `O_RDWR`                                                                   |

**Before:**

```python
class UpperTextLoader(BaseLoader[str]):
    def equal(self, other, equal_nan=False):
        return type(other) is type(self)

    def load(self, path):
        return sanitize_path(path).read_text().upper()
```

**After:**

```python
class UpperTextLoader(BaseLoader[str]):
    def _load(self, path):
        return path.read_text().upper()
```

A caller that needs mutual exclusion around a read-modify-write of one file takes a lock of its own
around the read and the write: `save` never provided it. A temporary file `.<name>-<uuid><ext>` left
by a process killed during a save is hidden and safe to delete.

### 9. Identifier: Four Generators Removed, Strict Inputs, One Clock Rule

`generate_uuid4`, `generate_nano_id`, `generate_prefixed_id`, `generate_obfuscated_id` and
`decode_obfuscated_id` are removed: each is a line of the standard library or, for the obfuscated
identifiers, an affine map that two known pairs break. The stable identifiers keep their values.

| Before                   | After                                                                          |
| ------------------------ | ------------------------------------------------------------------------------ |
| `generate_uuid4()`       | `str(uuid.uuid4())`                                                            |
| `generate_nano_id(n, a)` | `secrets.token_urlsafe(16)`, or `"".join(secrets.choice(a) for _ in range(n))` |
| `generate_prefixed_id`   | `f"cus_{generate_ulid()}"`                                                     |
| `generate_obfuscated_id` | a library made for it (`sqids`), or a keyed permutation; never an affine map   |

The inputs are strict, and the extractors are the strict inverse of the generators:

| Before                                                                    | After                                                                          |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
