    Registry

    coola.registry ¶

    General-purpose registry primitives used across the package.

    Registry is a thread-safe key-value container and TypeRegistry adds the lookup of the most specific registered type (Method Resolution Order). Both are generic, keep the insertion order, return snapshots from items, keys and values, raise AlreadyRegisteredError on a duplicate unless exist_ok=True, copy independently with copy, survive os.fork and load the entries of optional libraries lazily (register_lazy). See the registry user guide for the details.

    coola.registry.AlreadyRegisteredError ¶

    Bases: ValueError

    Raised when registering a key that is already registered and exist_ok is False.

    It is a ValueError (the value passed is not acceptable in the current state of the registry).

    Example 
    >>> from coola.registry import AlreadyRegisteredError, Registry
>>> registry = Registry[str, int]()
>>> registry.register("key", 1)
>>> try:
...     registry.register("key", 2)
... except AlreadyRegisteredError:
...     print("already registered")
...
already registered

    coola.registry.Registry ¶

    Bases: Generic[K, V]

    A thread-safe generic key-value registry for storing and managing typed mappings.

    The Registry class provides a type-safe container for registering and retrieving values by key. It supports all standard dictionary operations through operator overloading and provides additional methods for safe registration and querying.

    The state is a dictionary that is replaced on every write and never mutated, so the reads take no lock, items(), keys() and values() return snapshots, and a writer never shows a partial state to a reader. The writers are serialized by one reentrant lock. TypeRegistry extends this class.

    Parameters:

    Name Type Description Default
    initial_state dict[K, V] | None

    An optional dictionary to initialize the registry with. If provided, a copy is made to prevent external modifications. Defaults to None, which creates an empty registry.

    		 None

    Attributes:

    Name Type Description
    _state dict[K, V]

    Internal dictionary storing the key-value pairs. It is replaced, never mutated.
    _lock RLock

    Threading lock for synchronizing the writers.

    Raises:

    Type Description
    TypeError

    If a key is not valid for the registry.
    Example

    Basic usage with registration and retrieval:

    >>> from coola.registry import Registry
>>> registry = Registry[str, int]()
>>> registry.register("key1", 42)
>>> registry.get("key1")
42
>>> registry
Registry(
  (key1): 42
)

    Using dictionary-style operations:

    >>> from coola.registry import Registry
>>> registry = Registry[str, int]()
>>> registry["key2"] = 100
>>> "key2" in registry
True
>>> del registry["key2"]

    Initializing with existing data:

    >>> from coola.registry import Registry
>>> registry = Registry[str, int](initial_state={"a": 1, "b": 2})
>>> len(registry)
2

    coola.registry.Registry.clear ¶

    clear() -> None

    Remove all entries from the registry.

    This method empties the registry, leaving it in the same state as a newly created empty registry. This operation cannot be undone.

    Example

    coola.registry.Registry.register_many ¶

    register_many(
    mapping: Mapping[K, V], *, exist_ok: bool = False
) -> None

    Register multiple key-value pairs in a single operation.

    This is a convenience method for bulk registration. It iterates through the provided mapping and registers each key-value pair. All registrations follow the same exist_ok policy. The operation is atomic with respect to this registry when exist_ok is False: either every key-value pair in mapping ends up registered, or (if any key already exists) none of them do - there is no partial registration. This says nothing about atomicity across multiple registries: if mapping is registered into several registries in sequence, each register_many call is atomic on its own, but the overall multi-registry operation is not - a failure on a later registry does not roll back an earlier one.

    Parameters:

    Name Type Description Default
    mapping Mapping[K, V]

    A dictionary or mapping containing the key-value pairs to register. The keys and values must match the registry's type parameters.

    		 required
    exist_ok bool

    Controls behavior when any key already exists. If False (default), raises error on the first duplicate key. If True, overwrites all existing values without error.

    		 False

    Raises:

    Type Description
    AlreadyRegisteredError

    If exist_ok is False and any key in the mapping is already registered. The error occurs on the first duplicate encountered, and no partial registration occurs.
    TypeError

    If a key is rejected by the registry. No key is registered.
    Example

    Registering multiple entries at once:

    >>> from coola.registry import Registry
>>> registry = Registry[str, int]()
>>> registry.register_many({"key1": 42, "key2": 100, "key3": 7})
>>> registry.get("key1")
42
>>> registry.get("key2")
100
>>> len(registry)
3

    Bulk update with exist_ok:

    >>> registry.register_many({"key1": 1, "key4": 4}, exist_ok=True)
>>> registry.get("key1")
1
>>> registry.get("key4")
4

    coola.registry.TypeRegistry ¶

    Bases: Registry[type, T], Generic[T]

    A thread-safe type-based registry for storing and retrieving values.

    The TypeRegistry class provides a thread-safe container for mapping Python types to values. It supports standard dictionary operations through operator overloading and provides methods for safe registration and querying.

    The registry uses the Method Resolution Order (MRO) for type lookup through the resolve() method. When resolving a type, it automatically selects the most specific registered type, walking up the inheritance hierarchy if needed. This makes it ideal for type-based dispatching systems.

    The registry includes an internal cache for type resolution, bounded to _MAX_CACHE_SIZE (1024) entries. The cache is a plain dictionary that is filled under the lock and replaced by an empty one on any change of the registry, so cache hits in resolve() are lock-free and do not contend under threads. When the cache is full, it is reset rather than evicting entries. It holds strong references to the types, so a dynamically created class stays alive until the cache is reset.

    A type that cannot be a key (every dataclass, the classes that define a method, the virtual subclasses of an abstract base class) is supported by registering a fallback predicate with register_fallback. The order of precedence of resolve() is: the registered types (MRO order, object excluded), then the fallbacks (registration order), then object.

    Note: resolve() walks dtype.__mro__, which reflects real (static) inheritance only. Virtual subclasses registered via abc.ABCMeta.register() do not appear in __mro__, so registering a value for an ABC does not make resolve() match that ABC's virtual subclasses even though isinstance would report them as instances of the ABC. See resolve() for details.

    A fallback on issubclass is deliberately not provided. Many built-in types are virtual subclasses of Sequence (str, bytes, range, memoryview...), so such a fallback would send str to the handler registered for Sequence and, for instance, iterate over a string character by character. Register the virtual subclass explicitly instead.

    Parameters:

    Name Type Description Default
    initial_state dict[type, T] | None

    An optional dictionary to initialize the registry with. If provided, a copy is made to prevent external modifications. Defaults to None, which creates an empty registry.

    		 None

    Attributes: _state: Internal dictionary storing the type-value pairs. _cache: Bounded dictionary of type resolution lookups, filled under the lock and replaced by an empty one on any change. _fallbacks: The (predicate, handler) pairs in registration order. The dictionary is replaced on write, never mutated. _lock: Threading lock for synchronizing access to both state and cache.

    Raises:

    Type Description
    TypeError

    If a key is not a type.
    Example

    Basic usage with registration and retrieval:

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry.register(int, "I am an integer")
>>> registry.get(int)
'I am an integer'
>>> registry
TypeRegistry(
  (<class 'int'>): I am an integer
)

    Using dictionary-style operations:

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry[str] = "I am a string"
>>> str in registry
True
>>> registry[str]
'I am a string'
>>> del registry[str]
>>> str in registry
False

    Initializing with existing data:

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[int](initial_state={str: 100, float: 200})
>>> len(registry)
2
>>> registry.get(str)
100

    Using resolve() with inheritance (MRO lookup):

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry.register(object, "I am an object")
>>> registry.register(int, "I am an integer")
>>> # Direct match
>>> registry.resolve(int)
'I am an integer'
>>> # Falls back to parent type via MRO
>>> registry.resolve(bool)  # bool inherits from int
'I am an integer'
>>> # Falls back to object
>>> registry.resolve(str)
'I am an object'

    Bulk registration:

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry.register_many({int: "integer", float: "float", str: "string"})
>>> len(registry)
3
>>> registry.get(float)
'float'

    coola.registry.TypeRegistry.register_fallback ¶

    register_fallback(
    predicate: Callable[[type], bool],
    value: T,
    *,
    exist_ok: bool = False,
) -> None

    Register a value for the types accepted by a predicate.

    A fallback supports the types that cannot be a key of the registry, for example every dataclass, the classes that define a method, or the virtual subclasses of an abstract base class. resolve tries the fallbacks, in registration order, only if no registered type (object excluded) matches, and before object. The predicate must be pure and cheap: its result is cached per type until the next change of the registry. A predicate that raises propagates and is not cached.

    Parameters:

    Name Type Description Default
    predicate Callable[[type], bool]

    A function that takes a type and returns True if value handles it.

    		 required
    value T

    The value to return for the types accepted by predicate.

    		 required
    exist_ok bool

    If False (default), raises an error if the predicate is already registered. If True, replaces the value and keeps the position of the predicate.

    		 False

    Raises:

    Type Description
    AlreadyRegisteredError

    If the predicate is already registered and exist_ok is False.
    Example 
    >>> from collections.abc import Sequence
>>> from collections import deque
>>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]({object: "object"})
>>> registry.register_fallback(lambda t: issubclass(t, Sequence), "sequence")
>>> registry.resolve(deque)
'sequence'

    coola.registry.TypeRegistry.register_lazy ¶

    register_lazy(
    packages: str | Sequence[str],
    factory: str | Callable[[], Mapping[type, T]],
) -> None

    Register entries that are built the first time they are needed.

    This is used to register the handlers of an optional library without importing the library when the registry is created. The group is loaded the first time the registry is asked for a type that comes from one of the packages (the top-level package of the type or of one of its base classes), or for the whole content of the registry (len, iteration, items, keys, values, equal). repr, copy and register_lazy load nothing.

    The entries that are loaded never replace the entries that are already registered, so a type that was registered by hand keeps its value. A group whose factory raises stays pending, so the next access raises again. Two groups with a package in common both stay and are both loaded. clear removes the groups that are not loaded.

    Parameters:

    Name Type Description Default
    packages str | Sequence[str]

    The name or the names of the top-level packages of the group. The group is loaded when a type from any of these packages is needed.

    		 required
    factory str | Callable[[], Mapping[type, T]]

    A callable that returns the entries, or its path "package.module:name". A path is imported when the entries are loaded.

    		 required
    Example 
    >>> from decimal import Decimal
>>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry.register_lazy("decimal", lambda: {Decimal: "decimal"})
>>> registry.resolve(Decimal)
'decimal'

    coola.registry.TypeRegistry.resolve ¶

    resolve(dtype: type) -> T

    Resolve a type to its associated value using MRO lookup.

    This method finds the most appropriate value for a given type by walking the Method Resolution Order (MRO). It first checks for a direct match, then searches through parent types in MRO order to find the most specific registered type.

    Results are cached internally to optimize performance for repeated lookups of the same type.

    Note

    Resolution walks dtype.__mro__, i.e. real (static) inheritance only. Virtual subclasses registered with abc.ABCMeta.register() do not appear in __mro__, so registering a value for an ABC does not make this method resolve any of that ABC's virtual subclasses, even though isinstance(instance_of_virtual_subclass, the_abc) is True. To make a virtual subclass resolve to a value, either register the subclass itself or a real (non-virtual) ancestor of it.

    Parameters:

    Name Type Description Default
    dtype type

    The type to resolve.

    		 required

    Returns:

    Type Description
    T

    The value associated with the type or its nearest registered
    T

    parent type in the MRO.

    Raises:

    Type Description
    TypeError

    If dtype is not a type.
    TypeNotRegisteredError

    If no matching type is found in the registry, including parent types in the MRO.
    Example

    Basic resolution with inheritance:

    >>> from coola.registry import TypeRegistry
>>> registry = TypeRegistry[str]()
>>> registry.register(object, "base")
>>> registry.register(int, "integer")
>>> # Direct match
>>> registry.resolve(int)
'integer'
>>> # bool inherits from int, so resolves to int's value
>>> registry.resolve(bool)
'integer'
>>> # str inherits from object, so resolves to object's value
>>> registry.resolve(str)
'base'

    Resolution with custom classes:

    >>> from coola.registry import TypeRegistry
>>> class Animal:
...     pass
...
>>> class Dog(Animal):
...     pass
...
>>> class Poodle(Dog):
...     pass
...
>>> registry = TypeRegistry[str]()
>>> registry.register(Animal, "animal")
>>> registry.register(Dog, "dog")
>>> registry.resolve(Dog)
'dog'

    coola.registry.default.reset_default_registries ¶

    reset_default_registries() -> None

    Forget the default registries, so the next use of each of them builds a new one.

    Every default registry (equality testers, hashers, summarizers, ...) is rebuilt with its default entries and its plugins, and the registrations that were made with the register_* functions, and the calls to clear or unregister, are dropped. A registry that was obtained before the reset is not changed.

    Example 
    >>> from coola.equality.tester import get_default_registry
>>> from coola.registry.default import reset_default_registries
>>> get_default_registry().clear()
>>> reset_default_registries()
>>> get_default_registry().has_equality_tester(int)
True

    coola.registry.default.temporary_default_registries ¶

    temporary_default_registries() -> Generator[None]

    Restore the default registries when the context exits.

    Inside the context, the default registries that are already built are replaced by a copy (copy), so a registration, an unregister or a clear does not change the original. The default registries that are not built yet are built inside the context and forgotten when it exits. It is meant for tests that register a type, so they do not leak the registration to the other tests of the process.

    The default registries are process-wide: do not enter the context in several threads at the same time.

    Yields:

    Type Description
    Generator[None]

    None. The default registries are restored when the block exits.
    Example 
    >>> from coola.equality.tester import DefaultEqualityTester, get_default_registry
>>> from coola.registry.default import temporary_default_registries
>>> class Point:
...     pass
...
>>> with temporary_default_registries():
...     get_default_registry().register(Point, DefaultEqualityTester())
...     get_default_registry().has_equality_tester(Point)
...
True
>>> get_default_registry().has_equality_tester(Point)
False

    coola.registry.plugins.load_registry_plugins ¶

    load_registry_plugins(registry: object, group: str) -> None

    Populate a registry from third-party entry points.

    Each entry point in group must resolve to a callable that takes the registry and registers its types on it. A plugin that fails to load or run emits a RuntimeWarning and is skipped, so one broken plugin cannot break coola. The failure is also logged with its traceback. If the COOLA_STRICT_PLUGINS environment variable is set (e.g. in CI), every plugin is still attempted and all failures are then raised together as an ExceptionGroup, each annotated with the plugin name and group. If the COOLA_DISABLE_PLUGINS environment variable is set, no plugin is loaded. The plugins that were loaded are listed by get_loaded_plugins.

    Parameters:

    Name Type Description Default
    registry object

    The registry passed to each plugin.

    		 required
    group str

    The entry-point group to load, e.g. "coola.equality.testers".

    		 required

    Raises:

    Type Description
    ExceptionGroup

    If COOLA_STRICT_PLUGINS is set and at least one plugin failed to load or run.
    Example 
    >>> from coola.registry.plugins import load_registry_plugins
>>> load_registry_plugins({}, "coola.nonexistent.group")
