    Equality

    coola.equality ¶

    Utilities to compare nested objects for exact or tolerant equality.

    The package exports the comparison functions, the result, the configuration, the engine, the testers and the registry. The testers of the optional libraries (NumPy, PyTorch, JAX, xarray, pydantic) are imported the first time they are used.

    coola.equality.AttributeName ¶

    Bases: str

    Name of an attribute in the location of a difference.

    It is a str that marks a path component as an attribute (a dataclass field, for example) rather than a key or an index, so a path is formatted as ['a'][2].x and not as ['a'][2]['x'].

    Example 
    >>> from coola.equality._helpers.utils import AttributeName
>>> AttributeName("x") == "x"
True

    coola.equality.BaseEqualityTester ¶

    Bases: InlineDisplayMixin, ABC, Generic[T]

    Define the base class to implement an equality operator.

    The engine owns the invariants of a comparison (identity, strict type, depth, cycles, location of the first difference). A tester never recurses: objects_are_equal receives the two objects, which have the same type, and the engine, and returns

    • a verdict: True, or ctx.fail(reason, *path) (which returns False) for a leaf;
    • or the child pairs (actual, expected, path part) that must all be equal, produced lazily and in the order the first difference is wanted, for a container.

    Two testers are equal if they have the same type and the same attributes. A child class with parameters must override _display_fields.

    Example 
    >>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import BaseEqualityTester, get_default_registry
>>> class PointTester(BaseEqualityTester[tuple]):
...     def objects_are_equal(self, actual, expected, ctx):
...         return ((actual[0], expected[0], 0), (actual[1], expected[1], 1))
...
>>> registry = get_default_registry().copy()
>>> registry.register(tuple, PointTester(), exist_ok=True)
>>> Engine(EqualityConfig(registry=registry)).run((1, 2), (1, 2))
True
>>> Engine(EqualityConfig(registry=registry)).run((1, 2), (1, 3))
False
>>> PointTester() == PointTester()
True

    coola.equality.DataclassEqualityTester ¶

    Bases: BaseEqualityTester[Any]

    Implement an equality tester for dataclass instances.

    The two instances have the same type, and the tester compares their fields, in the order of declaration. The fields with compare=False are ignored. The fields are compared with the engine, so they support the tolerance and equal_nan, and the location of a difference is the name of the field.

    Example 
    >>> from dataclasses import dataclass
>>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import get_default_registry
>>> @dataclass
... class Point:
...     x: float
...
>>> engine = Engine(EqualityConfig())
>>> engine.run(Point(1.0), Point(1.0))
True
>>> engine.run(Point(1.0), Point(2.0))
False

    coola.equality.DefaultEqualityTester ¶

    Bases: BaseEqualityTester[object]

    Implement a default equality tester.

    This tester serves as the fallback for types without specialized equality testers. It uses Python's built-in == operator to test equality between two objects of the same type. The engine checks the identity and the type before the tester is called.

    This tester is registered for the object type in the default registry, making it the catch-all for unregistered types via Python's MRO.

    Raises:

    Type Description
    TypeError

    if == raises a TypeError or a ValueError, or returns a value that cannot be converted to a bool (for example an array). False would claim that the objects are different when they were not compared at all.
    Example 
    >>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import DefaultEqualityTester, get_default_registry
>>> engine = Engine(EqualityConfig())
>>> tester = DefaultEqualityTester()
>>> tester.objects_are_equal("meow", "meow", engine)
True
>>> tester.objects_are_equal("meow", "meov", engine)
False

    coola.equality.DifferenceCloseEqualityTester ¶

    Bases: BaseEqualityTester[Any]

    Implement an equality tester for decimal.Decimal, fractions.Fraction and datetime.timedelta.

    These types have no allclose, so the tester compares their difference with the tolerance (see difference_close). A Decimal NaN is equal to a NaN only if equal_nan is True, and atol of a timedelta is a number of seconds.

    This tester is registered for Decimal, Fraction and timedelta in the default registry.

    Example 
    >>> from coola.equality import Tolerance
>>> from decimal import Decimal
>>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import DifferenceCloseEqualityTester, get_default_registry
>>> registry = get_default_registry()
>>> tester = DifferenceCloseEqualityTester()
>>> tester.objects_are_equal(
...     Decimal("1.0"), Decimal("1.00001"), Engine(EqualityConfig())
... )
False
>>> tester.objects_are_equal(
...     Decimal("1.0"), Decimal("1.00001"), Engine(EqualityConfig(tolerance=Tolerance(atol=1e-3)))
... )
True

    coola.equality.Engine ¶

    Run the comparison of two objects.

    One engine runs one comparison. For each pair of objects, the engine checks the identity, the strict type, finds the tester (the lookup is cached for the call) and calls it. A tester that uses the engine returns either a bool (the verdict) or an iterator of (actual, expected, path part) child pairs that must all be equal. The iterators are kept on an explicit stack, depth first, so the first difference in iteration order is the one found and nothing after it is visited. The stack use is constant: there is no RecursionError whatever the nesting.

    Parameters:

    Name Type Description Default
    config EqualityConfig

    The settings of the comparison (the registry that finds the tester of a type, the tolerance, equal_nan and max_depth). A config is immutable and can be shared.

    		 required
    explaining bool

    If True, the reasons are built and the first difference is recorded in failure.

    		 False

    Attributes:

    Name Type Description
    atol

    The absolute tolerance.
    rtol

    The relative tolerance.
    equal_nan

    If True, two NaNs are equal.
    explaining

    If True, the reasons are built.
    failure tuple[tuple[object, ...], str | None] | None

    None or, after a difference was found, the pair (path, reason) of the first difference.
    Example 
    >>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> Engine(EqualityConfig()).run([1, {"a": 2}], [1, {"a": 2}])
True
>>> Engine(EqualityConfig()).run([1, {"a": 2}], [1, {"a": 3}])
False

    coola.equality.EqualEqualityTester ¶

    Bases: BaseEqualityTester[object]

    Implement an equality tester for objects with equal method.

    This tester is designed for objects that implement an equal(other) method for equality comparison. The two objects have the same type (the engine checks it) and the tester calls the equal method of the first one. An object without a callable equal is different.

    Example 
    >>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import EqualEqualityTester, get_default_registry
>>> class MyFloat:
...     def __init__(self, value: float) -> None:
...         self._value = float(value)
...     def equal(self, other: object) -> bool:
...         if type(other) is not type(self):
...             return False
...         return self._value == other._value
...
>>> engine = Engine(EqualityConfig())
>>> tester = EqualEqualityTester()
>>> tester.objects_are_equal(MyFloat(42), MyFloat(42), engine)
True
>>> tester.objects_are_equal(MyFloat(42), MyFloat(1), engine)
False

    coola.equality.EqualNanEqualityTester ¶

    Bases: BaseEqualityTester[object]

    Implement an equality tester for objects with equal method that supports NaN equality.

    This tester is designed for objects that implement an equal(other, equal_nan) method. The tester calls the equal method of the first object with equal_nan of the comparison. An object without a callable equal is different.

    Example 
    >>> import math
>>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import EqualNanEqualityTester, get_default_registry
>>> class MyFloat:
...     def __init__(self, value: float) -> None:
...         self._value = float(value)
...     def equal(self, other: object, equal_nan: bool = False) -> bool:
...         if type(other) is not type(self):
...             return False
...         if equal_nan and math.isnan(self._value) and math.isnan(other._value):
...             return True
...         return self._value == other._value
...
>>> registry = get_default_registry()
>>> tester = EqualNanEqualityTester()
>>> nan1, nan2 = MyFloat(float("nan")), MyFloat(float("nan"))
>>> tester.objects_are_equal(nan1, nan2, Engine(EqualityConfig()))
False
>>> tester.objects_are_equal(nan1, nan2, Engine(EqualityConfig(equal_nan=True)))
True

    coola.equality.EqualityTesterRegistry ¶

    Bases: TypeRegistry[BaseEqualityTester[Any]]

    Registry that manages and dispatches equality testers based on data type.

    This registry maintains a mapping from Python types to equality tester instances and uses the Method Resolution Order (MRO) for type lookup. When checking equality, it automatically selects the most specific registered equality tester for the data's type, falling back to parent types or a default tester if needed.

    The registry includes an internal cache for type lookups to optimize performance in applications that repeatedly check equality of similar data structures.

    Parameters:

    Name Type Description Default
    initial_state dict[type, T] | None

    Optional initial mapping of types to equality testers. If provided, the state is copied to prevent external mutations.

    		 None

    Attributes:

    Name Type Description
    _state dict[K, V]

    Internal mapping of registered types to equality testers
    Example

    Basic usage:

    >>> from coola.equality.tester import (
...     EqualityTesterRegistry,
...     SequenceEqualityTester,
...     DefaultEqualityTester,
... )
>>> from coola.equality.config import EqualityConfig
>>> registry = EqualityTesterRegistry(
...     {object: DefaultEqualityTester(), list: SequenceEqualityTester()}
... )
>>> registry
EqualityTesterRegistry(
  (<class 'object'>): DefaultEqualityTester()
  (<class 'list'>): SequenceEqualityTester()
)
>>> config = EqualityConfig()
>>> registry.objects_are_equal([1, 2, 3], [1, 2, 3], config=config)
True

    coola.equality.engine.Engine ¶

    Run the comparison of two objects.

    One engine runs one comparison. For each pair of objects, the engine checks the identity, the strict type, finds the tester (the lookup is cached for the call) and calls it.     Bases: BaseEqualityTester[object]

    Implement an equality tester for objects that support both allclose and equal methods.

    This tester is designed for objects that implement both an allclose(other, rtol, atol, equal_nan) method for tolerance-based comparison and an equal(other, equal_nan) method for exact comparison. The tester calls allclose when a tolerance is not zero, otherwise equal. An object that does not have both methods is different.

    Example 
    >>> from coola.equality import Tolerance
>>> import math
>>> from coola.equality.config import EqualityConfig
>>> from coola.equality.engine import Engine
>>> from coola.equality.tester import TolerantEqualEqualityTester, get_default_registry
>>> class MyFloat:
...     def __init__(self, value: float) -> None:
...         self._value = float(value)
...     def allclose(
...         self,
...         other: object,
...         rtol: float = 1e-5,
...         atol: float = 1e-8,
...         equal_nan: bool = False,
...     ) -> bool:
...         if type(other) is not type(self):
...             return False
...         if equal_nan and math.isnan(self._value) and math.isnan(other._value):
...             return True
...         return math.isclose(self._value, other._value, rel_tol=rtol, abs_tol=atol)
...     def equal(self, other: object, equal_nan: bool = False) -> bool:
...         if type(other) is not type(self):
...             return False
...         if equal_nan and math.isnan(self._value) and math.isnan(other._value):
...             return True
...         return self._value == other._value
...

True
>>> tester.objects_are_equal(MyFloat(1.0), MyFloat(1.4), Engine(EqualityConfig()))
